# 2026-09-26

- A two-stage Diligent AssetLoader split (CPU parse on a worker thread via a `ModelCreateInfo::DeferGPUResources` + `LoadFromFile(…, nullptr, …)` that retains host vertex/index data, then `Model::FinishGPUResources(device, ctx)` for the immutable buffer creates on the render thread) introduced a latent heap corruption: do NOT ship the split until the out-of-bounds is isolated. The safe phase-5 win is to parallelize only the pure-CPU half (pak read + zstd → byte cache) on the thread pool and overlap the one-time GPU texture-cache fill with it (loadWorld 349.7→255–264 ms). Fingerprint: the animation-source Model (a *plain non-defer* load, `DeferredData` null) read a correct `Nodes.size()` in a check immediately before `animSourceSetup`, then SIGSEGV'd *inside* it at `animSource->Nodes.size()`, triggered by the `make_unique<ModelTransforms>()` malloc a couple of lines earlier — i.e. a latent out-of-bounds in the defer load/finish corrupting heap *metadata* that a later allocation trips over, not a use-after-free of the anim Model. The corruption survived moving the retained data out of the `Model` object into a heap `unique_ptr` struct (so it is not a `sizeof(Model)`/member-layout issue); both inline-in-Model and heap-struct storage corrupted. ASan could not isolate it: an ASan build (game `-fsanitize=address` + AssetLoader `target_compile_options -fsanitize=address`) crashes in radv Vulkan init during physical-device enumeration, before the world load. Incident: world-load plan phase 5 — parallel tinygltf parse reverted, Diligent AssetLoader back to stock; re-attempt needs a working ASan/heap-checker path for the loader.

- Diligent `RefCntAutoPtr::operator&()` returns a *temporary* `DoublePtrHelper` whose destructor (end of full-expression) is what attaches the out-param to the smart ptr — so `if (factory->Create(name, &ptr) && ptr)` reads `ptr` BEFORE the transfer lands and is always false. Split the call and the null-check into separate statements (`const Bool ok = factory->Create(name, &ptr); if (ok && ptr)`). Fingerprint: an out-param API into a `RefCntAutoPtr` "succeeds" (returns true) but the ptr is still null on the very next token in the same expression; adding any statement between the call and the check makes it work. Incident: world-load plan phase 3 — the SPIR-V shader cache silently skipped all 5 file-path (DiligentFX memory-factory) IBL shaders; the stream was created fine but `&& stream` short-circuited on the pre-transfer null.
- URI-referenced KTX2 images cannot go through Diligent's GLTF loader file path — its KTXLoader throws `ktx2.0 is not currently supported` (KTXLoader.cpp). Serve them via `ModelCreateInfo::pTextureCache` pre-filled from the engine TextureManager (weak refs; the manager's strong ref keeps them alive): tinygltf's FileExists/ReadWholeFile and `Model::AddTexture` all short-circuit on a cache hit and no Diligent texture loader runs. The raw-RGBA8 ktx2 need a concrete format — carry it in the filename semantic suffix and mirror Diligent's `GetPBRTextureSRV` color-slot list (base/emissive/diffuse/clearcoat/sheen-color sRGB, everything else linear; unknown slot = linear, that is also what the PBR renderer does with typeless textures). Incident: world-load plan phase 2 — props/eve textures as external ktx2; eve 193→9 ms, props render with the real textures the pak had silently lost.
- To let a statically-linked third-party lib call into your disk caches via `extern "C"` helpers, the helper DEFINITIONS must be a separate archive member (e.g. a fallback .cpp in the lib) — never inline bodies in the shared header: the inline is INLINED into the lib's TU, your strong symbols are never referenced, and the patch is a SILENT NO-OP (no link error, no warning that matters). Fingerprint: `nm` on the lib's object shows no `U fx*` refs and the first-frame timing is unchanged; `clang` warns `-Wreturn-type-c-linkage` on the inline decl. Archive-member fallbacks resolve only when the symbol is still undefined at that archive's turn (game links libc-engine.a before libDiligentFX.a → game's strong defs win; samples get the fallback).
