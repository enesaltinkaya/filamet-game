# 2026-09-13

- A "camera-distance" value read from the TRANSPOSED runtime matrix is a different axis entirely: `diligentFrameView()` is the runtime-glslang transposed view, so the focus-band / cascade-pick code reading `view._31.._33` got the true view's third COLUMN (a near-perpendicular dot → focusCamZ ≈ 0.07 instead of 10.85) — cascade 0 stayed at the raw log split (0–4.7 m, pure sky at third-person vantages), every ground pixel fell to the 80 m cascade (~8 texel/m, the player's whole shadow ≈ 3 texels) and PCF erased it. Fingerprint: `shadow trace ... band 3.1` constant while the player sits ~11 m out, and `ENGINE_SPLAT_SHADOW_DEBUG=3` all-magenta (c0 uv-branch never runs) while `ENGINE_SHADOW_ORACLE` passes (it never tests camZ). Fix: read the true z row from the transposed matrix (`view._13/_23/_33`); same fix in the PBR receiver cascade pick.
- Automated runs must never write the state db: the menu-enter flow (ENGINE_AUTOTEST=enter) ends with the player/orbit ACTIVE, the character slides off her parked spot, and `PlayerSystem::postUpdate`'s 1 Hz periodic saves overwrite BOTH the `player` row (her slid position) and the `camera` row (the orbit eye) — one screenshot run is enough to destroy a parked setup. Fingerprint: `flying camera: loaded saved state pos (...)` logging coordinates you never parked. Fix: gate the periodic saves with `automatedRun()`; restore clobbered rows from a pre-session byte dump (capture `select data from camera/player` BEFORE the first automated run of a session).
- "Shadow invisible" at a known-good parked vantage is a CONTRAST bug, not a caster bug — measure before touching the shadow pipeline: `ENGINE_SPLAT_SHADOW_DEBUG=2` (attenuation to screen; blob present ⇒ caster+receiver fine) then a scanline brightness profile across the shadow in the beauty frame. This engine is IBL-dominated (env carries the sun disk): direct sun adds only ~20% over ambient, so a PCF-correct shadow was a ~10% sRGB dip — unreadable on scree albedo. Mitigated with ambient-in-shadow darkening (`f4ShadowFade.w`, `ENGINE_SHADOW_AMBIENT_DARKEN`, default 0.5), not a sun/IBL rebalance.
- Automated runs skip the saved-camera restore by design (scripted vantages own the view); `ENGINE_CAMERA_DB=1` opts back into the parked camera row for screenshot verification.
