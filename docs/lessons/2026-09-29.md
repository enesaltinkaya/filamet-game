# 2026-09-29

- "AO ghosts when the camera moves" is DiligentFX SSAO temporal accumulation by design: `SSAO_ComputeTemporalAccumulation.fx` reprojects the AO history with the OBJECT motion vectors only (`GetClosestMotionVectors` — zero for static terrain/props), so camera motion never reprojects it; α = 1/history with `SSAO_MAX_HISTORY_LENGTH 16` keeps ~94% stale screen-space AO every frame → occlusion trails ~16 frames. The shader's own comment says it: "Higher values reduce noise for the price of increased ghosting". Fix = per-frame `ResetAccumulation` while the camera moves (eye-translation-at-near-depth + view-rotation, both converted to px/frame, `ENGINE_AO_MOTION_RESET` default 0.1, 0 = ghost baseline); static frames keep accumulating so the half-res AO stays denoised. Diagnostic fingerprint: AO maps bit-identical with `ENGINE_SSAO_NO_HISTORY` on the same motion sequence; on a 1 m/s dolly the AO-vs-no-history delta tracks the dolly speed (0.39→0.17 MAD as the turnaround decelerates); `ENGINE_SSAO_RESET_TRACE` + per-frame `_moved.txt` sidecar (`ENGINE_STAGE_DUMP` burst now writes `N_depth.png` + `N_moved.txt` with dEye/dRot/camera basis). Distinct from the 2026-09-28 GTAO smear entry — that one was spatial and camera-static.

- A character depenetration pass MUST be rate-limited, never applied as a full-depth teleport in one tick: any collider penetrating deeper than `recoverySpeed × dt` then out-speeds the jump. Fingerprint: `JOLT_DEBUG depenetrate` firing on EVERY tick with the same depth and a constant axis, ground state 0 (`OnGround`) while the position never moves. Incident: "she cant jump" — the green lawn (`Plane` node of `models/test2`, props body 38, a 582×582 m sheet at Y=0 centred on the origin, `innerLocalSize=(582.1,0.0,582.1)`) gave `depth=0.700 axis=(0,1,0)` on all 213 ticks = 0.7 m/tick = a 42 m/s downward shove against a 4 m/s jump. Fix: `joltCharacterUpdate` clamps its step to `GetPenetrationRecoverySpeed() * dt` (1.0 m/s → 0.017 m/tick, log now reads `depth=0.700 step=0.017`) — the same rate Jolt's own `CharacterVirtual` uses (`CharacterVirtual.cpp:650`). Measured on the lawn from the parked spot: stands at feet y=0, jumps to 1.01 m, lands, repeats. A zero-thickness sheet IS a valid floor — the lawn is the ONLY floor at x 71.5 z 2.1 (terrain surface there is 689 m on a 40–52° flank, so the parked vantage sits under the mountain): do NOT filter sheets out of the sidecar. The first fix attempt dropped the `Plane` entry (28 → 27 bodies) and she fell through the green floor; the collider stays, the depenetration rate was the bug. Probes: `JOLT_TEST_CAST` straight down (the sheet is the only hit), `JOLT_DEBUG static` create lines for the AABB, `ENGINE_AUTO_JUMP=N` (jump every N fixed ticks; pair with `ENGINE_AUTO_RUN=1`); `ENGINE_TELEPORT` runs are now gated out of the periodic `player`/`camera` saves (probe runs clobbered the parked rows twice).
