# 2026-09-08

- `ShaderCreateInfo.Source` is INLINE source code; the stream-factory file path is the separate `FilePath` member — `ci.Source = "CubemapFace.vsh"` made glslang compile the filename as a shader declaration ("ERROR: :1: 'declaration' : Expected" for every FX shader, silently leaving IBL off). DiligentFX FX shaders need `ci.FilePath` + `ci.pShaderSourceStreamFactory = &DiligentFXShaderSourceStreamFactory::GetInstance()` (PBR_Renderer.cpp:797/807/868)
- FX precompute shaders declare the sampler explicitly as `<texture>_sampler` (ComputeIrradianceMap.psh:19 `SamplerState g_EnvironmentMap_sampler;`) — an `AddImmutableSampler(..., "g_EnvironmentMap", ...)` layout variable names the SAMLER variable `g_EnvironmentMap`, so the real `g_EnvironmentMap_sampler` stays unbound: "No resource is assigned to static shader variable 'g_EnvironmentMap_sampler' in the Implicit signature" + VUID-vkCmdDraw-None-08114 on every draw, draw reads an undefined sampler. Name the immutable variable with the `_sampler` suffix (PBR_Renderer does this for material textures, PBR_Renderer.cpp:1250)
- Prefiltered envmap cubemap mip count must be the full chain for its dim (256² → 9, not 16): VUID-VkImageCreateInfo-mipLevels-00958/02255, and the roughness→mip mapping assumed 16 mips so the max-roughness mip was outside the texture
- The Diligent IBL port dropped the old engine's SPECULAR-ONLY IBL attenuation (VulkanIbl's IBL_SPEC_INTENSITY=0.5, applied to `prefilterColor` in scene.frag) — with the port's IBLScale=1.0 the dielectric character (eve roughness 0.54) reads as "very shiny" vs the old engine/Blender while matte terrain/props (roughness 0.9) look fine. Restored by pointing the PREFILTER pass at a specular-scaled env copy (IblDiligent `envSpecTex`, scaled CPU-side on load; the irradiance/diffuse pass keeps the full env) — a per-frame uniform can't do it because DiligentFX's IBLScale scales diffuse+specular together. Knobs: ENGINE_IBL_INTENSITY (global, also the DebugGui IBL intensity ±0.25), ENGINE_IBL_SPEC_INTENSITY (spec-only, re-runs the prefilter on change)
- "Still too shiny vs Blender with the 0.5 damp in": the env HDRI (kloofendal puresky) contains its own sun disk (peak ~29800 nits, 38% of total env flux) only ~8° from the analytic sun (elev 54° vs disk 47.5°) — the scene lights the sun twice, and the spec lobe prefilters the disk into a sheen spike on anything reflecting near the sun direction (character back viewed while facing the sun: mirror R ≈ sun dir; measured prefiltered spec 1.38 with disk vs 0.29 sans disk at roughness 0.54). Fixed with a luminance clamp on the SPECULAR env copy only (uploadSpecEnvironment, ENGINE_IBL_SPEC_CLAMP default 100, ≤0 off) — the analytic sun supplies that energy via direct GGX spec; diffuse keeps the full env (old-engine behavior). Blender reference reads matte because HDRI-world lighting has no second sun.
