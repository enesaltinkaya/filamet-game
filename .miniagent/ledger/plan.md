# Plan — fix "blocky square-plane leaves" on ported ez-tree

## Strategy

The ported deciduous tree draws its leaves with `treegen`'s CARDS strategy: only 1-2 crossed
square cards per terminal tip (`cardCountMin=1`/`cardCountMax=2` in `configDeciduous()`), each
sampling a random 45-90% sub-rect of the 128px procedural texture
`c-game/data/pak_1/images/leaf-textures/ash.png` (generated by `scripts/make_leaf_sprite.py`),
whose leaf region holds ~70 sparse 8-15px leaflet discs with transparent gaps and a clear
transparent border. A frame-1200 headless screenshot (`/tmp/tree_before.png`) confirms the
result: big solid-green rounded-square cards with transparent holes — exactly the "square plane
objects" the user reports. The reference `/var/home/enes/Downloads/tree.png` (exported from the
original ez-tree) uses 16 leaf cards per max-level branch (`leaves.count=16`, size 2.67,
sizeVariance 0.72, angle 55, double billboard, alphaTest 0.5, roundedNormals) over a dense
high-res leaf-cluster texture: the dense overlapping tangle hides every card silhouette. So the
fix is leaf density + texture content, not branch geometry: regenerate `ash.png` with a dense
field of small leaflets filling the sampled region edge-to-edge (larger canvas, e.g. 256px),
raise the per-tip card count toward the original's 16, retune `cardSize`/sub-rect sampling and
the `kBarkUvRect`/`kLeafUvRect` constants to the new layout, repack `pak_1.pak` with
`scripts/data.sh`, and iterate on headless screenshots until the canopy matches the reference
with no visible square silhouettes. Texture binding, the DECIDUOUS `ALPHA_TEST` flag, the cutout
discard in `props_ps.hlsl`, the v=0=image-top UV convention and pak contents are all verified
working (no renderer changes expected); `conifer/acacia/shrub` use other treegen strategies and
must stay untouched apart from shared constants.

## Pinned verification

Every verifier round runs this ONE command (builds via run.sh, runs the game headless ~30 s,
captures a lossless PNG of the framed close-up tree at frame 1200, auto-exits):

Verification: ENGINE_HIDDEN_WINDOW=1 VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/radeon_icd.json TERM=xterm-256color ENGINE_SCREENSHOT=/tmp/tree_after.png ENGINE_SCREENSHOT_FRAME=1200 ENGINE_LOG_TIMEOUT=30000 bash scripts/run.sh

Then the verifier reads `/tmp/tree_after.png` and compares it against
`/var/home/enes/Downloads/tree.png` (canopy must read as a dense natural leaf tangle; no square
card silhouettes), and checks the `azgaarPropMesh build` log line (deciduous tri counts sane,
validation PASS). Note: `ENGINE_LOG_TIMEOUT` is in **milliseconds** (90 exits after 0.09 s —
use 30000 for a 30 s run).
